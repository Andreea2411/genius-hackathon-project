## Project Description
   Terra Guard is a disaster preparedness web application that helps people prepare for natural disasters such as floods, 
   earthquakes, wildfires, hurricanes, and heat waves. By collecting basic information from users, the platform provides
   personalized safety recommendations, customized emergency backpack checklists, and interactive quizzes to improve disaster
   awareness and preparedness. Its goal is to help communities stay informed, reduce risks, and respond more effectively during emergencies.

## Problem Addressed
   Many people are not adequately prepared for natural disasters and do not know what actions to take before an emergency occurs. Our project 
   focuses primarily on disaster preparedness, helping users understand risks and prepare effectively in advance. We aimed to address a wide range 
   of natural disasters, including floods, earthquakes, wildfires, hurricanes, extreme heat waves, blizzards, and other hazardous events. By
   providing personalized recommendations, emergency supply checklists, and educational quizzes, Terra Guard helps communities become more resilient
   and better prepared for potential disasters.

## Features
 - Personalized Safety Recommendations – receive disaster-specific guidance based on your situation and risk factors.
 - Custom Emergency Kit Checklist – get a custom list of essential supplies for your specific disaster scenario.
 - Interactive Learning Quizzes – test and reinforce your preparedness knowledge through engaging quizzes.

## Technology Used
 HTML: Used for the semantic structure and accessibility of the web pages.
 CSS: Used for responsive web design , advanced UI effects , dynamic styling based on user input , and smooth keyframe animations.
 JavaScript : Vanilla JavaScript used for the core algorithmic engine, DOM manipulation, event handling, and algorithmic resource allocation without relying on heavy frameworks.
 
 Frameworks & Libraries
 Vanilla Web Stack: The core platform runs on pure HTML/CSS/JS for maximum speed and zero dependencies.
 Chart.js: An open-source JavaScript library used via CDN to render the dynamic, responsive line chart on the "Impact" page (visualizing the casualty reduction over time).

 APIs & Integrations
 Google Forms (Iframe Integration): Used as an external, secure microservice to host the interactive "Test Your Knowledge" quiz module without requiring a custom backend database.
 Unsplash Image Delivery: Used for dynamic, high-quality, and responsive background image fetching via direct URL parameters.

 Datasets & Data Structures
 Proprietary JavaScript Objects: Instead of external datasets, the algorithmic engine uses built-in localized data arrays and object mappings (e.g., mapping ⁠disaster⁠ types to specific ⁠housing⁠ risks and ⁠backpack⁠ logistics) for instantaneous processing.
 Statistical Data: Hardcoded statistical data arrays used within Chart.js to map disaster impact metrics over a 24-hour timeline.
 
 AI Tools Used 
 Generative AI (Google Gemini and ChatGPT): Utilized as a pair-programming assistant for code optimization, logic structuring, debugging, UI/UX ideation, and copywriting for safety protocols.
 

## How To Run The Project
- Open the deployed application using the provided public link.
- Complete the requested information.
- Explore the personalized disaster preparedness recommendations.
- Review the customized emergency kit checklist.
- Take the interactive quiz to test your knowledge.

No installation, downloads, or additional software are required. The project can be accessed directly through a web browser.
